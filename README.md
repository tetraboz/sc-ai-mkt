# sc-ai-mkt

日本の半導体関連4銘柄の開示を使った、10:30 JST の購入判断の検証。マイポックス（5381）、新報国マテリアル（5542）、ニッカトー（5367）、ジェイテックコーポレーション（3446）を対象とし、日経半導体ETF（200A）を比較に使う。

**業績指標のみの検証は13候補・2取引。朝の値動きの追加効果は未検証。** 対象期間は判定日で2025-11-01〜2026-05-31、価格・配当の評価期限は2026-11-24。結果の解釈、各取引と開示指標の例は [検証結果](results/report.md) に記載。

## 再実行

Python 3.11以上。標準ライブラリと JST のタイムゾーンデータを使用。

```sh
python tools/fetch_daily.py
python backtest.py --out results/reproduced
```

日足の取得済みスナップショットが `data/raw/` にあれば、2行目だけで再計算できる。日足の再取得時は配信元の履歴訂正などでデータが変わりうる。`run.json` に入力ファイルの SHA-256 を記録する。日足の生データはローカルに保存する。

5分足を入手した場合は、下記の形式に揃え、同じ期間と取引ルールで両方を実行する。

```sh
python backtest.py --intraday /path/to/five_minute.csv --out results/with_morning
```

期間と評価期限は `--start`、`--end`、`--as-of` で指定できる。対象期間を変えるときは、その前の開示スナップショット、25営業日の履歴、評価期限までの日足も用意する。東証の営業日一覧があれば `--calendar` に `session` 列（YYYY-MM-DD）のCSVを渡せる。今回の営業日には200Aの日足の日付を使用した。

## 入力データと時刻

| データ | 今回の入力・時刻 |
| --- | --- |
| 会社予想・実績 | [data/fundamentals.csv](data/fundamentals.csv)。各社の決算短信・修正開示を転記。各行に原資料のURL、開示時刻、期間の開始日・終了日、連結・単体、EPSの株式数基準を記録。 |
| 市場予想 | 決算発表直前に取得できた同じ期間・同じ指標の市場予想スナップショットは確保できず、実績12件の市場サプライズはすべて欠測。市場予想を追加する場合は `kind=consensus` とその取得可能時刻を記録する。 |
| 受注 | 3446の2026-02-13 17:00公表資料15ページの前年同期比較を採用。受注確定分と受注確度の高い案件を合わせた定義で、連結全体・事業別の中間期末残高。受注高の比較可能な数値は今回の入力に含まれない。 |
| 日足・配当・分割 | Yahoo Finance の日足チャート、4銘柄と200A、2024-12-01以上・2026-11-25未満を2026-11-25 12:59 JST頃に取得。時刻は取引所の営業日に変換。価格に含まれる分割調整を分割イベントから戻して当時の円価格を求める。配当は権利落ち日ベース。 |
| 5分足 | 検証期間の入力なし。Yahoo Financeの照会は過去60日までとして拒否された。J-Quantsの過去分足は別途契約が必要。 |

古い開示の公表時刻は、発行体資料の日付と [5381の開示一覧](https://kabuyoho.jp/reportDisclose?bcode=5381)、[5542の開示履歴](https://s.kabutan.jp/stocks/5542/news/?news_category_id=3)、[5367の開示一覧](https://kabuyoho.jp/reportDisclose?bcode=5367)、[3446の開示一覧](https://disclosure.catr.jp/companies/fd8c0/69042/disclosures) などで確認した。新しい開示は [Yahoo!ファイナンスの開示一覧](https://finance.yahoo.co.jp/quote/3446.T/disclosure) のTDnet配信時刻を参照。分足の入手先と仕様は [J-Quantsのプラン](https://jpx-jquants.com/ja?lang=ja) と [分足の仕様](https://jpx-jquants.com/ja/spec/eq-bars-minute) を参照。

5分足のCSVヘッダーは次のとおり。

```csv
code,end_jst,available_at_jst,status,open,high,low,close,volume
```

- `end_jst` は5分区間の終了時刻。09:05の行が09:00以上09:05未満の約定を表す。入力は当時の円価格と株数。1分足を集約する場合は時刻境界を合わせ、始値は最初、終値は最後、高値・安値は最大・最小、出来高は合計とする。
- `available_at_jst` はその行の値が当時の情報源で取得可能になった時刻。双方に `+09:00` などのタイムゾーンを付ける。事後訂正の値には訂正後に知り得た時刻を使う。履歴配信の提供日は、当時の相場配信時刻の証拠にならない。
- `trade` は約定あり。`no_trade` は配信の完全性を確認した区間の約定なしで、価格は空欄、出来高は0。`missing` は配信欠損で価格・出来高が空欄。行の欠落や判定時点で未取得の区間も欠損として扱う。配信仕様だけで区別できない空白は欠損とする。

## 指標と売買ルール

- **業績**。同一銘柄・期の開始日と終了日・会計範囲の直前の会社予想から、EPSと営業利益の差額および符号の変化を算出。新旧どちらかのEPSが1円以下なら差額を使い、双方が1円超なら修正率も記録する。実績の市場サプライズと会社予想との差を別系列にし、実績発表と同時刻の予想は比較から外す。受注高と受注残は指標、定義、範囲、期間が揃ったときだけ前年同期比を算出する。
- **朝**。9:30と10:00までの足で、前営業日終値比、当日の初回約定価格比、観察時刻までの高値比、200Aの前日比との差（ポイント）を計算。出来高倍率の分母は、直前25営業日の同じ観察時刻までの累積出来高の中央値。25日が揃い中央値が正のときだけ倍率を出す。全区間約定なしは `no_trade`、過去に約定したが直近区間に約定がない場合は `stale`、データ欠損は `missing`。5分足の範囲で鮮度を判定する。ATRは使用していない。
- **判定**。対象開示を取り込める最初の営業日の10:30に、同じ銘柄の対象開示をまとめて判定。直前の会社予想からの修正、実績の対会社予想差、実績の対市場予想差のうち、いずれか同じ比較でEPSと営業利益がともに正なら業績側は買い候補。受注は記録指標とした。
- **朝の追加条件**。業績側の買い候補に対し、9:30と10:00の株とETFの足が揃い、双方の相対騰落差が0ポイント以上、10:00の始値比が0%以上・高値比が−2%以上・出来高倍率が1倍以上なら買い候補とする。条件は固定で、過去リターンによる閾値探索は行っていない。
- **評価**。判定後の翌営業日の寄り付きで100株。購入代金と買いコストの合計を12万円以下とする。両戦略とも片道0.20%のコストを置き、買いから1・3・6暦月後の当日または次営業日の終値で売却した場合を評価する。取引は開示ごとに独立、配当は税引前で算入。200Aは同じエントリー日と退出日で期間リターンを計算する。寄り付きと引けの価格は日足による近似で、板の厚さ、100株の約定順、実際の税や手数料は再現していない。判定日の終値を入力に使っていない。

## 出力

| ファイル | 内容 |
| --- | --- |
| `fundamentals.csv` | 開示と比較元の資料・時刻、数値、修正額、率、符号の変化、受注比較 |
| `morning.csv` | 時刻ごとの朝の指標と欠測区分 |
| `returns.csv` | 銘柄・判定日・手法・保有期間ごとの約定、除外理由、控除後リターン |
| `summary.csv` | 手法ごとおよび銘柄ごとの件数とリターン |
| `paired_summary.csv` | 朝の指標が揃う同一候補での比較。全体の結果とともに、見送りを現金での0%とした候補単位の平均も表示 |
| `run.json` | データの範囲、評価条件、入力のチェックサム |

過去リターンで条件を調整する場合は、後の検証期間を先に確保し、学習側の取引の評価期限が検証期間に重ならないように区切る。
